Conectar con GitHub

¿Cómo obtengo el token? (1 minuto)
  1. Entra a github.com/settings/personal-access-tokens → Generate new token (fine-grained).
  2. En Repository access elige Only select repositories → tu repo Lenadores2001.
  3. En Permissions → Repository permissions → Contents, ponlo en Read and write.
  4. Elige una expiración (ej. 90 días), genera y copia el token (empieza con github_pat_).
Configuración del repositorio (avanzado)

El token es como una llave que solo abre este repositorio (permiso de escribir archivos). No se guarda en la web pública; los visitantes solo ven la galería.
